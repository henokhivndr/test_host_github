# 🚀 CloudHost - Responsive Landing Page

Template *landing page* modern, bersih, dan sepenuhnya responsif untuk layanan cloud hosting. Project ini dirancang menggunakan HTML5, CSS3 vanilla, dan JavaScript modern tanpa menggunakan framework external, sehingga sangat ringan dan cocok untuk dideploy langsung menggunakan **GitHub Pages**.

## ✨ Fitur Utama
*   **Desain Modern & Minimalis:** Kombinasi warna profesional yang memberikan impresi tepercaya.
*   **Fully Responsive:** Tampilan otomatis menyesuaikan dengan layar HP, Tablet, maupun Laptop/Desktop.
*   **Smooth Scroll:** Navigasi yang mulus antar section (*Fitur*, *Harga*, dan *Kontak*).
*   **Interactive UI:** Dilengkapi efek bayangan dinamis pada navbar saat di-scroll dan alert interaktif pada tombol paket.
*   **Kecepatan Maksimal:** Tanpa library pihak ketiga, memastikan performa loading page yang instan.

## 📁 Struktur Project
```text
├── index.html      # Struktur utama halaman web
├── style.css       # Pengaturan tata letak, warna, dan animasi (CSS)
├── script.js      # Logika interaktivitas dan efek scroll (JS)
└── README.md       # Dokumentasi panduan project
```

## 🛠️ Langkah-Langkah Penggunaan & Deploy ke GitHub

Ikuti panduan berikut untuk menjalankan project ini di komputer Anda dan mengunggahnya ke internet secara gratis menggunakan GitHub Pages:

### 1. Persiapan Lokal
1. Buat sebuah folder baru di komputer Anda (misalnya diberi nama `cloudhost-landingpage`).
2. Di dalam folder tersebut, buat tiga buah file kosong bernama `index.html`, `style.css`, dan `script.js`.
3. Salin (*copy*) masing-masing kode yang sudah disediakan sebelumnya, lalu tempel (*paste*) ke dalam file yang sesuai.

### 2. Upload ke GitHub
1. Masuk ke akun [GitHub](https://github.com/) Anda.
2. Buat repository baru dengan menekan tombol **New** (atau tanda `+` di kanan atas).
3. Beri nama repository Anda (misal: `cloudhost-page`), atur menjadi **Public**, lalu klik **Create repository**.
4. Unggah (*upload*) ketiga file tersebut (`index.html`, `style.css`, `script.js`) langsung ke root repository Anda.

### 3. Mengaktifkan GitHub Pages (Hosting Gratis)
1. Buka halaman repository yang baru saja Anda buat di GitHub.
2. Masuk ke menu **Settings** (ikon gerigi di bagian atas).
3. Pada bilah menu sebelah kiri, cari dan klik menu **Pages** (di bawah kategori *Code and automation*).
4. Di bagian **Build and deployment** -> **Source**, pastikan terpilih `Deploy from a branch`.
5. Di bagian **Branch**, ubah dari `None` menjadi `main` (atau `master`), dan biarkan folder tetap `/ (root)`.
6. Klik tombol **Save**.
7. Tunggu sekitar 1 sampai 2 menit. Refresh halaman tersebut hingga muncul banner berwarna hijau yang berisi tautan URL web Anda (contoh: `https://username.github.io/cloudhost-page/`).
